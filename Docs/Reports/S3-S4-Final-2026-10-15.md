## 사용 방법과 책임

[UserGuide 25~28절](../UserGuide.md#25-게임-저장-세션과-실행-재개)에 공개 C++/Blueprint API, Details 설정, 실패 반환/이벤트, 게임 확장 예제와 검증 명령을 기록했다.

- 게임이 같은 합본 상태를 복원한 뒤 CheckpointSession/RestoreController를 연결한다. 정확 복원에는 신규 조건 필터를 적용하지 않는다.
- 교체 매핑이 있을 때만 대체 Block 처음부터 진행한다. 버전 범위 중첩·교체 순환·누락/중복 ID는 실패한다.
- SelectiveRollback은 보존 원본 Graph, 이번 실행의 통과 Line, 실제 효과 성공 원장을 요구한다. 과거 누적 읽음만으로 회수하지 않는다.
- 게임은 CorrectionProvider에서 원자 보정과 영수증을 구현한다. 샘플은 출처가 입증된 Count Add만 회수하며 다른 경로 Add를 유지한다. 소비·Set·Tag·Value 등은 게임별 정책 없이는 실패한다.
- 보정 후 대체 BlockStart를 먼저 메모리 캡처하고 비동기 저장 중 진행한다. 접수 실패는 동일 자료 재시도, 파일 실패는 FIFO 재시도다. 강제 종료 시 마지막 온전한 저장 전체를 복원한다.
- 초기화 preflight와 외부 제공자 재진입 방어를 추가했다. 저장 불가이면 이력을 먼저 지우지 않는다.

## 검증 증거

모든 경로는 프로젝트 루트 상대 경로다. 자동화의 Error 허용 수는 0이다.

| 검증 | 결과 | 증거 |
|---|---|---|
| S3 세션 회귀 | 39개 통과 | Saved/AI/20261015_150009_4c1fa116 |
| S4 정확 버전 회귀 | 40개 통과 | Saved/AI/20261015_150716_5aa4c5ad |
| 교체·보정 회귀 | 42개 통과 | Saved/AI/20261015_152147_b20ea1a3 |
| 최종 Editor 빌드 | 성공 | Saved/AI/20261015_152817_1890a503 |
| 최종 DialogueKit 전체 | 42개 통과, Error 0 | Saved/AI/20261015_152840_16e59443 |
| 실제 프로세스 Write | 1개 통과, Error 0 | Saved/AI/20261015_152635_d59f8538 |
| 다른 PID에서 Read/정확 복원/사망 후 신규 선정 | 1개 통과, Error 0 | Saved/AI/20261015_152646_6173b360 |
| 최종 Win64 Development 패키징 | 성공, 실행하지 않음 | Saved/AI/Package_20261015_153012_5cad3ca9 |
| 실제 cooked Registry | 2개 통과, Error 0 | Saved/AI/20261015_153121_3ec1303c |

재시작 wrapper 결과: `Saved/AI/RestoreValidation/9b3e9bdc8b4b41b1bc923858b30a484f/result.json`. 최초 wrapper의 package와 cook도 통과했으며, 마지막 preflight 재진입 수정 후 전체 회귀와 패키지를 다시 검증했다. 공개 wrapper는 생성 전용 GUID 경로와 슬롯만 사용하며 증거를 삭제하지 않는다. `.uasset` 검증 자료는 Git ignore이고 코드·스크립트로 재생성한다.

초기 신규 테스트의 Validate 호출 인자 오류와 RuleId 비결정적 기본 초기화 오류를 수정했다. RuleId는 Details 편집/명시적 C++ 신규 생성에서 발급한다. 실제 writer가 부여하는 Revision을 커스텀 테스트 writer에 반영한 뒤 모두 재검증했다. 실패 로그는 보존한다.

독립 검토: ue_senior_reviewer(Sol Medium)의 큐 소유권·원본 근거·초기화/preflight·재진입 지적을 수정했고 ue_research_scout(Luna High)가 재시작/cook 증명 범위를 조사했다. 메인만 구현·Git·빌드·테스트했다. GameDirector 역할은 노출되지 않아 제품 검토를 실행하지 않았다. 기존 EnhancedInput 의존성/XGE 라이선스 경고는 남아 있다.

## Git과 복구

| 기능 | 기능 커밋/통합 |
|---|---|
| 저장 세션 | d34fa48, fc21676 / e2f8dd1 |
| 정확 버전 | 880680a와 후속 저작 커밋 / 176145d |
| 명시적 교체 | 1fc91c6, 27e8c7f / 592cece |
| 초기화 재진입 보완 | 3ae5499 |
| 실제 재시작/cook 검증·최종 문서 | feature/dialogue-restore-validation의 후속 커밋 및 Codex_Develop merge |

기능별 Branch를 보존하고 작은 Subject/Description 커밋 후 `--no-ff`로 통합한다. 기능 전체 복구는 해당 merge에 `revert -m 1`을 적용하되 의존하는 후속 기능부터 검토한다. 일부 수정만 복구할 때도 저장 계약 의존성을 확인한다. 실제 되돌리기는 사용자 Git 정책에 따른다. 기존 미통합 WIP `feature/dialogue-read-history`/3ac33bd는 삭제하지 않았다.
