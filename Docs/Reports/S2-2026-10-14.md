## 1. 완료 범위

2026-10-14 사용자 승인에 따라 S2 최소 Graph 저작·파일 왕복·실행을 완료했다. 기준은 S1 통합 `5ae3a57`, 구현 통합은 `a4d54e5`다. 실제 저장 안전성, 고급 편집 도구와 화면/음향은 후속 단계이며 S2 완료에 포함하지 않는다.

| 항목 | 구현·검증한 내용 |
|---|---|
| Line | 독립 발화 자료, 단일 출력, 에셋과 분리된 표시 복사본 |
| Choice | 독립 목록, 개별 All/Any 조건, 일반 우선·기본 fallback, ChoiceId 기반 선택/재정렬 연결 보존 |
| Branch | Tag/Value/Count 공통 평가, True/False, 빈 조건·조회 오류 규칙, 자동 구간 순환 중단 |
| StateChange | 상태 변경 메뉴·Effects Details, 실제 진입 시 게임 제공자 요청, 성공 경계 후 자동 진행 |
| End | SaveOnEnd 기본 false, 완료/실패 구분, 완료 기록용 경계와 저장 요청 플래그 |
| 연결·왕복 | 입력 다중/출력 단일, 연결 교체, 공통 Codec, 저장 실패 시 기존 자료 보존, 실제 uasset 저장/언로드/재로드 |
| UI/API | 직접 다음 타입 한 단계 조회, Line과 직접 Choice 동시 데이터, Subsystem·Blueprint 동적 이벤트/기존 공개 조회 함수 브리지 |
| 기존 소비처 | 독립 Choice CSV 내보내기, Subsystem 지역화 조회 연결, 혼합 구형/신규 Graph 시작 전 거부 |

선택 전에는 Choice 이후 특정 경로를 제시하지 않는다. Branch 너머는 사전 평가하지 않는다. 사용자 입력을 거친 반복 질문/Branch 재방문은 허용한다. 실패는 정상 완료로 치환하지 않으며 게임 저장을 직접 호출하지 않는다.

## 2. 사용 방법과 변경 파일

[사용자 안내서 13~17절](../UserGuide.md#13-line-노드와-block-실행-기반)에 작가 UI 절차, 공개 API, 게임 확장 책임을 작성했다.

- 작가: DialogueGraph 생성 메뉴에서 Line·Choice·Branch·상태 변경·End를 배치하고 Details와 핀을 편집한다. 선택지 추가/삭제는 Choice Options 배열에서 수행한다.
- 개발자: `ConfigureBlockProviders` → 경계/UI 이벤트 바인딩 → `StartDialogueBlock` 순서다. 입력은 `AdvanceLine` 또는 `SelectBlockChoice(ChoiceId)`로 전달한다.
- 게임 제공자: `IDialogueStateProvider`, `IDialogueEffectProvider`, 진단 Router를 구현/연결한다. `OnExecutionBoundary`는 성공 직후 동기 알림이며 실제 디스크 저장 성공이 아니다.
- `bSaveRequested=false`인 선택/완료는 캐시 기록 경계다. true이면 게임이 그 시점의 상태·기록·재개 위치를 복사해 저장 조율자에 제출해야 한다. 실제 FIFO/복원 구현은 S3다.
- 기존 프로토타입 에셋은 자동 변환하지 않았다. 구형 Dialogue와 신규 노드를 섞어 실행하는 대신 수동 재작성한다. Prototype2는 수정하지 않았다.

## 3. 검증 결과

| 검증 | 결과·근거 |
|---|---|
| 최종 Editor Win64 Development 빌드 | 성공, `Saved/AI/20261014_222919_439f1121/Build.log` |
| 전체 DialogueKit 자동화 | **27개 성공**, `Saved/AI/20261014_223011_a7bc1397/Report/index.json` |
| S2 신규 테스트 | Graph 3개 + Runtime 5개. 기존 S1까지 19개와 함께 통과 |
| 실제 파일 왕복 | Line 단독 및 모든 신규 노드의 고유 임시 uasset 저장/언로드/재로드/재변환, ID·핀·효과·조건·End 설정 확인 |
| UI 계약 | Subsystem 공개 API와 Blueprint 동적 delegate 바인딩을 화면 없이 검증 |
| Game 패키징 | `Saved/AI/Package_20261014_223102_2722c993/result.json`, UAT 종료0, 새 exe/pak 확인, **PackagedNotLaunched** |
| Git·문서 | 명시 파일 stage, diff --check, Subject/Description, 기능별 비강제 push와 non-ff 통합 |

테스트 로그에는 기존 초기화 문제 6필드/12개 Error가 남아 있으며 새 Error는 0이다. EnhancedInput 의존성 선언 및 IncrediBuild 라이선스 경고도 기존 항목이다. 테스트 성공을 기존 오류 해소로 해석하지 않는다.

실패 후 수정한 항목:

- 첫 파일 왕복 시험에서 임시 경로를 조기 해제해 지연 Localization 검증이 실패했다(`215824_06a967fd`). 테스트 프로세스 수명까지 고유 경로를 유지하고 `Super::PreSave` 누락을 보완했다. 오류 허용 목록은 늘리지 않았다.
- Choice Codec payload 분기 누락으로 첫 Choice 시험이 실패했다(`221119_b227cf41`). 타입 검사를 추가해 해결했다.
- 독립 검토로 active 실행 덮어쓰기, 타입/본문 불일치, GC 수명, 숨은 선택 ID, Choice 전 경로 누출, 빈 선택 대기, no-effect ExecutionId 계약, 혼합 Graph의 효과 선실행 위험을 보완했다.

Sol Medium 검토자와 Luna High 조사자를 실제 사용했고 메인만 수정·Git·빌드·테스트했다. 최종 Sol Medium 검토에서 명백한 차단 없음. GameDirector 역할은 현재 제공되지 않아 제품 검토는 Unavailable/Not reviewed이며 다른 역할로 대체하지 않았다.

미실행/제한:

- 실제 GUI/PIE 화면·마우스/키보드·초상화/음향, 패키지 실행은 미검증이다. S6/S7에서 수행한다.
- 패키징은 기존 샘플 맵의 Game 빌드·cook·출력 검증이다. 임시 신규 Graph의 패키지 실행 검증과 구분한다.
- 신규 실행기의 실제 원자 저장/FIFO/실파일 복원·중복 수령 방어는 S3다. Subsystem 초기화에는 legacy 저장 초기화가 남아 있다.
- 일반 Save/SaveAs 변환 실패는 안내하지만 Save All/AutoSave의 전체 취소·상세 경고창은 S5 검증 UI 작업이다.
- 누적 열람/스킵, 최신 요청 후보 로드·버전 교체, 전체 지역화 호환 회귀는 후속 단계다.

## 4. Git 통합과 복구

모든 기능은 Codex_Develop에서 파생하여 구현/편집 연결/검증·문서의 작은 커밋으로 나누고 non-ff 통합했다. 기능 브랜치를 로컬·원격에 보존한다.

| 기능 브랜치 | 통합 merge | 부모1 기준 |
|---|---|---|
| feature/dialogue-line-node | `f6e241d` | `5ae3a57` |
| feature/dialogue-choice-node | `31dd1f7` | `f6e241d` |
| feature/dialogue-branch-flow | `7767987` | `31dd1f7` |
| feature/dialogue-statechange-node | `6eb3614` | `7767987` |
| feature/dialogue-end-flow | `a4d54e5` | `6eb3614` |

기능 전체를 되돌릴 때는 의존 후속 기능부터 역순으로 검토하여 해당 merge의 부모1 기준 revert를 사용한다. 커밋 제거/reset/rebase/force push는 자동 수행하지 않는다. 부분 복구는 기능 브랜치의 Subject/Description과 의존성을 확인한 뒤 필요한 커밋을 역적용한다. 초기 Choice 초안의 임시 stash도 보관했으며 최종 코드는 모두 기능 커밋에 포함되어 있다.
