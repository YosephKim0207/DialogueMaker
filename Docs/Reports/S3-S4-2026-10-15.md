## 1. 완료와 남은 작업

S3·S4 구현 요청에 따라 독립적으로 검증 가능한 기능을 통합했다. **S3·S4 전체 완료가 아니다.**

| 구분 | 항목 | 내용·상태 |
|---|---|---|
| 이전 완료 | S0~S2 | 검증 기반, 공통 계약, 최소 Graph 저작·실행 |
| 이번 완료 | S3 효과 상태/원장 | 같은 시점 상태·원장 복사와 검증 복원, 중복 실행 재전달 방어 |
| 이번 완료 | S3 저장 큐/샘플 | FIFO, 불변 payload, 실패 head 대기, 재시도, 세대 검증, 실제 비동기 합본 파일 |
| 이번 완료 | S4 메타데이터 | 정확 대상·Chapter/Scene·조건 무로딩 평가, 신규 노출 중단 |
| 이번 완료 | S4 후보/세션 | 최우선·일반·기본 순회, 완료/노출 분리, 세션 종료 초기화 |
| 이번 완료 | S4 독립 로더 | 최신 요청, 오래된 완료 차단, 공유 핸들 보호, 공통 인사 설정 |
| WIP/보류 | S3 누적 이력 | 3ac33bd 별도 브랜치. 알려진 복원 결함으로 미통합 |
| 남음 | S3 복원·통합 | Runner 재개, 열람 연결, 전체 저장 소비처, 강제 종료/별도 프로세스 재실행 |
| 남음 | S4 버전 정책 | 정확 구버전 복원, 버전 범위 매핑, 게임 보정, 스토리 초기화, 복원용 cook 포함 |
| 미착수 | S5 | 상속·경유점·복제·검색·검사 UI·스토리보드·미열람 갱신 |
| 미착수 | S6 | 텍스트/선택 표시·스킵·연출·음향·PIE 미리보기 |
| 미착수 | S7 | 전체 통합 회귀·배포 검증 |

## 2. 사용법과 변경 범위

[사용자 안내서](../UserGuide.md) 18~22절은 공개 함수와 실제 설정을 기준으로 작성했다. 큐/샘플과 로더를 게임이 소유하고, 대화 실행·로그 전송·팝업·이동/연타 제한을 게임 정책으로 연결한다. 로더 완료와 Runner 실행 성공을 구분하고 정상 End에서만 완료 기록을 호출한다. 기존 `BeginDialogue(Speaker)`는 자동 교체하지 않았다.

주요 변경:

- Runtime `DialogueSampleEffectProvider`: 상태·실행 원장 스냅샷.
- Runtime `DialogueSaveQueue`, `DialogueSampleSaveCoordinator`: 큐와 실제 비동기 저장 샘플.
- Runtime `DialogueGraph`, `DialogueBlockMetadata`: Registry 색인과 신규 선정 설정.
- Runtime `DialogueCandidateSelector`, `DialogueBlockLoader`, `DialogueSettings`: 선정·최신 로드·공통 인사 soft 참조.
- Runtime/Editor 테스트: 효과/큐/실파일, 후보, 늦은 완료/재진입, Registry 언로드/실제 비동기 로드, cooked Registry.
- 문서: UserGuide, Blueprint, DialogueImplementationPlan 및 본 보고서.

Prototype2, 기존 바이너리 콘텐츠, 엔진/외부 플러그인과 실제 사용자 저장은 수정하지 않았다.

## 3. 검증과 한계

| 검증 | 결과 |
|---|---|
| Editor Build | `20261015_115642_0db0f59c` 성공 |
| 전체 자동화 | `20261015_115703_57156fa8` **35개 성공**, 기존 Error 12/신규 0 |
| 실제 저장 파일 | 격리 슬롯 비동기 저장→새 객체 복원, 미저장 상태 배제·원장 복원, 손상된 다른 슬롯 무시 |
| 실제 에셋 | 임시 패키지 저장/언로드→Registry 조건 평가→비동기 로드, 공유 에셋 한 핸들 취소, 캐시 재요청 |
| 패키징 | `Package_20261015_115728_2f64d1a7` UAT 성공, 새 exe/pak, **미실행** |
| cooked Registry | `20261015_115934_3c396ea4` 성공. 기존 샘플의 신규 tag/PrimaryAssetId 보존 확인 |

패키징과 cooked tag 보존이 구버전 복원 에셋/매핑 검증을 뜻하지 않는다. 임시 Registry fixture와 mount는 지연 에디터 참조 때문에 프로세스 수명까지 유지하며 파일은 Saved/AI/RegistryTests 아래 시험 증거로 남는다. 실제 사용자 콘텐츠를 정리하지 않는다.

미실행: GUI/PIE·음향·패키지 실행·프로세스 강제 종료/재시작·Runner 저장 재개·Sentry 전송. 기존 초기화 오류와 EnhancedInput 의존성/빌드 라이선스 경고는 남아 있다.

실제 Sol Medium 검토자와 Luna High 조사자를 사용했고 메인만 수정·Git·빌드·테스트했다. 검토로 FIFO 재진입, 합본 ledger 검증, 최우선 동률, selector 세대, 같은 Block 요청 ID, 성공 후 CancelPending 의미를 보완했다. GameDirector는 사용 불가능하여 제품 검토 미실행이다.

실패 기록도 보존했다: 효과 시험의 배열 self-alias는 복사 후 추가로 수정, Editor native tag 초기화 오류는 Runtime 태그 조회로 수정했다. 오류 허용 목록을 확대하지 않았다.

## 5. 확인이 필요한 저장 변경

자동 승인 검토가 체크포인트 스키마 1→2 및 복원 의미 변경을 별도 사용자 확인이 필요한 저장 형식 변경으로 거부했다. 해당 변경은 적용하지 않았다.

승인 요청 범위: 새 저장은 스키마 2, 기존 스키마 1의 알려진 마지막 선택 이전, 정상 End 복원에서 포함된 임시 Choice 기록 정리, Choice 트리거/레코드 일치 검증. 기존 데이터의 해석이 달라지는 변경이므로 이전·손상·구버전 테스트 후 통합해야 한다.

현재 열람 초안은 End 저장 복원에서 임시 선택이 되살아날 수 있고 Choice 레코드 검증이 불충분하다. 초안의 31개 테스트 통과를 완료로 주장하지 않는다. 승인 후 이 결함을 해결하고 S3 재개·S4 버전 복원/교체/초기화를 이어간다.
